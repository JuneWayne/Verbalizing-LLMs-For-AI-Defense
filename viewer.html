Jlens training method
Switching Jlens training methods leaves the model's actual response unchanged. It changes the Jacobian matrix used to read the same hidden states, which can change the tokens and scores shown by Jlens. Logit lens uses no fitted Jacobian, so its verbalizations stay the same.
